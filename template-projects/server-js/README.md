# JavaScript + AppsScript

This template provides a minimal setup to get JavaScript working for an Apps Script Backend, scaffolded by [Gasbombe](https://ciderlabs.link/docs/gasbombe).

Currently, these plugins and tools are configured:

- [rolldown](https://github.com/rolldown/rolldown) for transpiling JavaScript files and bundling server-side files
